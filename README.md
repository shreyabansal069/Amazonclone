# Amazon Clone Website

A front-end web project designed to replicate the basic layout and user interface of the Amazon website. The project includes a responsive homepage with a navigation bar, product sections, banners, and footer design.

## Features

* Responsive homepage design
* Navigation bar and search section
* Product display sections
* Banner and footer layout
* Interactive front-end interface
